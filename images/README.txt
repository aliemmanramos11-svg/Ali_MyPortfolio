To replace any of them later:
- Save a new image file into this folder with the SAME name, or
- Keep a new file but update its <img src="..."> line in Portfolio.html
  (the project cards are in the "MY PROJECTS" section).

Tip: the cards crop each image to a 180px-tall band (object-fit: cover),
so a landscape screenshot works best. To show more of a tall screenshot,
raise the "height: 180px" value under ".project-card img" in style.css.
